## 🌌 New: Advanced Animated Sci-Fi Holographic Icons

Each of the 11 AI portal icons has been rebuilt with intricate, multi-layered cybernetic SVG vector art:
1. **Outer Gyroscopic Orbit Ring** (`.icon-gyro-ring`): Continuously rotates counter-clockwise with dashed telemetry brackets.
2. **Inner Counter-Rotating Tech Ring** (`.icon-counter-ring`): Smooth clockwise counter-rotation creating a multi-axis gyroscope illusion.
3. **Core Holographic Glyph** (`.icon-core-glyph`): Custom sci-fi emblem with glowing plasma breathing effects and drop-shadow bloom.
4. **Interactive Hover Acceleration**:
   - Hovering over any portal card speeds up the gyro ring from 16s down to 3s!
   - Blooms with a high-intensity neon cyan (`#00e5ff`) and violet (`#8a5cff`) laser glow.
   - The icon container lifts in 3D perspective with cybernetic rotation.
5. **Futuristic Cyber Badges**:
   - Beveled corner notches (`clip-path`) with glowing monospace sector tags.
